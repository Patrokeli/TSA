# Frontend – Student Management System

This is the frontend for the Student Management System built using **React**, **React Router**, and **Tailwind CSS**.

## 🧰 Technologies
- React.js
- React Router
- Tailwind CSS
- Axios

## 📂 Folder Structure

frontend/
├── src/
│ ├── components/
│ ├── pages/
│ ├── App.js
│ ├── index.js
│ └── index.css
└── package.json


## ⚙️ Setup Instructions

### 1. Install dependencies
```bash
npm install

2. Start the application
npm start

Application will run on:

http://localhost:3000

✨ Features

Add student
View list of students
Delete student
Connected to backend API
Styled using Tailwind CSS

🔗 Backend Connection

The frontend communicates with the backend at:

http://localhost:5000/api/students
